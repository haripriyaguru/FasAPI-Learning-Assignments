# 🚀 FastAPI 20 Basic Assignments

This repository contains **20 beginner-level assignments** completed while learning **FastAPI** and its core concepts. 🐍⚡

## 📚 About

The assignments cover the fundamentals of building **APIs and web applications** using FastAPI.

### 🧩 Topics Covered

- ⚡ FastAPI application setup
- 📥 GET and POST requests
- 🛣️ Path Parameters
- 🔍 Query Parameters
- 📤 Request and Response handling
- 📋 Response Models
- 🔢 HTTP Status Codes
- 📝 Form Data
- 📁 File Uploads
- 🎨 Jinja2 Templates
- 🖼️ Static Files
- 🗄️ SQLite Database
- 🔗 SQLAlchemy
- 🔐 Password Hashing
- 🔑 Authentication Basics
- 🍃 MongoDB
- 🧪 API Testing using Swagger UI
- 📦 Requirements Management
- 🔄 Basic CRUD Operations
